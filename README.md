# Iris's Counter

Independent offline Geometry Dash frame-window counter based on [Frame Window Lab](https://github.com/ImKubuuss/framecounterv2) (MIT).

The GitHub Actions workflow builds a Windows `.geode` for Geometry Dash 2.2081 without a license-key system. It is **not** FB Counter and does not import third-party macro recordings.

Build artifacts are available under **Actions → Build Iris's Counter → Artifacts**. Source is retrieved and customized at build time, with upstream credits and license preserved.
